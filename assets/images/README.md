# Emplacements pour vos photos

Les photos de la section JSP Muret Massat sont à fournir par vous. Déposez vos fichiers dans ce dossier :
- `jsp-muret-massat.png` : photo principale de la section JSP.
- `jsp-seance.jpg` : photo d'une séance de formation.

Les cadres correspondants dans la page afficheront automatiquement les images portant ces noms. Vous pouvez également ajouter ici vos photos de véhicules et de matériel, puis remplacer les cadres concernés dans `index.html` et `styles.css`.
